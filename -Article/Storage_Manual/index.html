A. Discordサーバーについて

今までMKの保管庫をほぼワンオペで拡張してきたのですが、一人の力には限界があります。そこで、複数人による開発をしようと考えました。
しかし、Scratchのサーバーだとこれらについて話し合う場所としては不便だと考えており、そういう理由で以下のDiscordサーバーを立ち上げました。

https://discord.com/channels/1523312184770429040/1523325704106676225
(多分招待されてない人は入れない...はず。)

今後MKの保管庫で執筆を担当する方は、できるなら会話の円滑化のためにもこのサーバーに入ってくれると嬉しいです。
このサーバーでは保管庫についての質問だったり、書き方のコツなどの共有、そのほか執筆場所の担当割り振りを行おうと思います。
このDiscordサーバーに入りたい場合は、まずアカウントを作りましょう。作ったら、https://scratch.mit.edu/users/mahirokkk/とかにサーバーに入りたい旨を書いてください。
Discordのユーザー名と一緒に書いてくれると助かります。そしたら僕が指示を出すのでその通りに動いてください。(暗号解読です。)
しっかり指示通りに動くとDiscordの招待リンクを見つけられるので、それにアクセスしてサーバーに参加してください。
あと注意点 : ScratchにDiscordという言葉をコメントすると悪い言葉検知器が反応してコメントブロックされます。
　　　　　　だから「保管庫執筆やってみたいです　アカウントはXXXXXXです」みたいにアカウントだけ書くことを強く推奨します。

2.Web開発環境を整える

VScodeは、デフォルトの状態でもWeb開発ができないわけではないが、拡張機能を使うことによって少しWeb開発を便利にすることができる。
その一つに「Live Server」なるものがある。この拡張機能、中で何が起こってるのかは参考記事を見てもらうとして、以下のメリットがある。

・ファイルの保存を検知して勝手にリロードしてくれる。
・ダウンロードの挙動をローカル環境で確かめられる。

まあ、これがあるとWeb開発がスムーズになる。実際に手元にHTMLファイルが無いと効果が分からないのだが...今はとりあえずダウンロードしよう
VS codeをインストールして日本語化までしている前提で話を進める。以下はLive Server導入の手順である。

1.まず、左タブの「拡張機能」と書いてあるところをクリック
2.検索ボックスに「Live Server」と入力
3.一番上に出てきたやつを押す
4.開発者が「Ritwick Dey」であることを確認したら、インストールする

ファイルエディタに戻ってみよう。そしたら、右下に Go Liveボタンがいつの間にかあるはずだ。
これを押すとブラウザが立ち上がり、自分が今作ってるウェブサイトが表示される。さらに、そのページはファイルが保存されるとそれを検知して自動でリロードしてくれるのだ!　 これで
「VScodeでコードを修正してCtrl+Sで保存」→「ブラウザですぐ変更を確かめる」
という流れが可能になり作業が効率化される。OFFにしたい場合は、先ほどのGo LiveボタンがPort:5500ボタンになってるので、これを押すと自動同期を止められる。
(補足 : 「Port:5500」の代わりに、「Stop Live Server」や「Disconnect from Live Server」等の表示が出る場合もある。)

GitHub

GitHubはWeb上の開発環境だ。この保管庫のみならず、多くの開発物がこのGitHubには入っている。便利だからだ。でもMKには難しすぎる。英語だし...
GitHubには「リモートリポジトリ」というものがあり、個人PCには「ローカルリポジトリ」がある。
ローカルリポジトリの内容をリモートリポジトリに移す、またはその逆といった行動の繰り返しによって開発物を発展させていくイメージだ。
ちなみにMKの保管庫は「Em-Keejp.github.io」というリモートリポジトリが元になって動いている。
GitHubはターミナルでコマンド打って操作するパターンもあるが、今回それは一切やらない。なぜなら全部VScodeで代用できるから。
とりま...まずアカウントを作らないと始まらない。自分で調べてアカウントを作ろう。

そしたら、リモートリポジトリをクローンして自身のPCに保存しよう。そうするとローカルリポジトリとして自身のPCにMKの保管庫が保存され、編集できるようになるよ。 ここでの変更はローカルリポジトリ内に留まるものであって、すぐにGitHubに反映されるものではないから、「無意識に荒らしちゃうかも...」という心配は無用だよ。
じゃあ、クローンしてみよう。

1.VScodeを開いて、左タブの「ソース管理」をクリック
2.「変更」タブの右にある3点リーダーをクリック
3.「クローン」をクリック
4.テキストボックスに、m-Keejp.github.ioリポジトリのURL https://github.com/Em-Keejp/Em-Keejp.github.io を入れる
5.複製先のフォルダを選択(事前に空のフォルダを作るといいかも)

リポジトリをクローンできたら、またもhttps://scratch.mit.edu/users/mahirokkk/に行ってもらって、今度はGitHubのアカウントを伝えよう。
MKが確認したら、Em-Keejp.github.ioリポジトリのコラボレーターに招待するから承認してね。
晴れてコラボレーター登録すると、Em-Keejp.github.ioリポジトリにブランチを切ったり、プルリクエストをする権利が与えられるよ。
なんか難しそうな機能名が出てきたけど、これらについてはまた「C. 保管庫拡充、編集の方法」にて解説するね。
ざっくり言うとクローンしたローカルリポジトリをGitHub上のリモートリポジトリに反映させる機能だよ。

C. 保管庫拡充、編集の方法

リモートリポジトリをクローンして、自分のPCに保存できたはず。そしたら、これを編集することで保管庫ことウェブサイトを編集できる。
基本的に編集内容はGitHubには反映されないから、好き勝手実験するといい。GitHubに編集を反映する方法は別で解説する。

保管庫特有のショートカットHTMLタグ

以下に紹介するのは、MKの保管庫のみで通用する特殊なHTMLタグだ。本来のHTMLにはこのタグを設定しても何も起きないが、MKが無理やりJavaScriptの力で使えるように改造した。 ちなみにできることはいずれも特殊なことではなく、タイトル通り書く量を少なくするためのショートカットとして導入されている。

<user>タグ

<user>mahirokkk</user>
mahirokkk

Scratchの対象のユーザーへのリンクを作る。


<url>タグ

<url name="MK　ビートころころ9">https://turbowarp.org/235811811?hqpen&offscreen</url>
https://turbowarp.org/235811811?hqpen&offscreen

対象のサイトへのリンクを作る。


<hi>タグ

<hi>強調文字</hi>
強調文字

強調文字を作る。class指定でhiを入れても同じことができる。なお、タグの方のhiは本文の強調以外は想定していない。
タイトルとかを強調するときはclass指定でhiを使おう。


<lo>タグ

<lo>(弱調文字)ですぅ...</lo>
(弱調文字)ですぅ...

弱調文字を作る。class指定でloを入れても同じことができる。なお、タグ、class指定双方で本文以外での使用は想定していない。
かっこ書きで注釈を入れたい時とかに使おう。
